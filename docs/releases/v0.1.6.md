# v0.1.6 — Scaled Battle Rewards

**发布日期：** 2026-06-23  
**代号：** 赏随阶升

战斗胜利后的**经验与金币**现同时受怪物 **tier** 与**等级**影响；Lv1 怪物数值与旧版一致，中后期高等级、精英与首领战收益更高。

## 战斗奖励

- 每只被击败怪物单独计算后求和；**tier 权重**：普通 1、精英 2、首领 5
- **等级系数** = `1 + (怪物等级 - 1) x 6%`（Lv10 约 1.54 倍，Lv20 约 2.14 倍）
- 经验基础 12、金币基础 7（均乘 tier 权重与等级系数）；金币总和仍受小队平均 **goldFindPct** 加成
- 示例：Lv1 普通 12 EXP / 7 金；Lv1 首领 60 EXP / 35 金；Lv10 首领约 92 EXP / 54 金
