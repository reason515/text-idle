# v0.1.0 — MVP Internal Test

**发布日期：** 2026-06-21  
**代号：** MVP 内测

首个可玩的 MVP 版本。核心放置战斗循环、小队成长、装备与商店、战斗统计与效率排行榜、音效表现层均已接入。

## 账号与存档

- 邮箱注册 / 登录，进度保存在服务端
- 序章队名，全服唯一校验
- 登出二次确认，进度保存在服务端

## 开局与小队

- 序章：欢迎 → 队名 → 固定战法牧三人开局
- 击败第 1 张地图 BOSS 后可招募第 4 人（限定德鲁伊）
- 击败第 2 张地图 BOSS 后可招募第 5 人（自选剩余英雄；**固定 2 初始技能**，无选技步）
- 小队最多 5 人；有空位时左栏可「+ 招募」

## 探索与战斗

- 五张地图：艾尔文森林、西部荒野、暮色森林、赤脊山、荆棘谷
- 回合制自动战斗：仇恨、目标选择、可暂停的战斗日志（含公式明细）
- 普通 / 精英 / 首领；探索度与 BOSS 解锁
- 战后休息恢复；离线推进沿用相同战斗规则

## 职业、技能与战术

- 可玩：战士、法师、牧师、德鲁伊
- 每 3 级强化技能、每 10 级学习新技能
- 英雄详情：属性、装备、技能、战术 AI（支持职业可配置优先级与目标）
- 属性与伤害公式在 tooltip 与日志中透明展示

## 装备与经济

- 背包 100 格：装备 / 卸下 / 出售
- 品质：普通、魔法、稀有、暗金；随机词缀
- 商店赌博：花金币购买未鉴定装备，购买后自动鉴定
- 胜利获得金币；寻宝（MF）影响商店品质概率

## 数据统计与排行榜

- 战斗统计 Modal：每探索步金币/经验效率、胜率、图表、伤害/受伤拆分、清零
- 效率排行榜：金币与经验各 TOP 10（最近 1000 探索步口径；总步数 ≥ 1000 方可上榜）

## 音效（表现层）

- 战斗与 UI 音效（CC0 样本 + 合成回退）；各地图进入主题
- 主音量与静音；偏好保存在浏览器 localStorage
