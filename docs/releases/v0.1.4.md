# v0.1.4 — Production Load Performance

**发布日期：** 2026-06-21  
**代号：** 轻装上阵

优化页面加载：精简静态资源体积，延迟音效预加载，提升首屏打开速度。

## 加载与静态资源

- 移除未使用的 **zpix** 字体与 **音效预览** 目录，构建产物由约 **12.6 MB** 降至约 **5.7 MB**
- 去掉 **Google Fonts** 外链，统一使用本地 **Ark Pixel** 像素字体，避免国内访问 Google CDN 拖慢首屏
- 页面打开时**不再立即预加载全部战斗音效**（约 3 MB）；改为**首次点击或按键**后再后台加载，首次战斗仍会按需拉取样本
