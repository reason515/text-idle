# v0.1.4 — Production Load Performance

**发布日期：** 2026-06-21  
**代号：** 轻装上阵

优化生产环境页面加载：精简静态资源体积，延迟音效预加载，并为嵌入前端增加 gzip 与浏览器缓存策略。

## 加载与静态资源

- 移除未使用的 **zpix** 字体与 **音效预览** 目录，构建产物由约 **12.6 MB** 降至约 **5.7 MB**
- 去掉 **Google Fonts** 外链，统一使用本地 **Ark Pixel** 像素字体，避免国内访问 Google CDN 拖慢首屏
- 页面打开时**不再立即预加载全部战斗音效**（约 3 MB）；改为**首次点击或按键**后再后台加载，首次战斗仍会按需拉取样本

## 服务端与缓存

- Release 二进制静态服务为 **JS/CSS/HTML** 启用 **gzip** 压缩
- 带 hash 的 `/assets/*` 设置长期缓存；`/fonts/`、`/audio/` 缓存 7 天；`index.html` 每次校验更新

## 本版本未包含

- 仍无 CDN、HTTPS 域名部署（内测仍可通过 IP + 端口访问）
- 战术 AI 解析仍依赖玩家自行配置 SiliconFlow API Key

## 反馈

欢迎在团队渠道反馈加载速度、音效延迟与缓存更新后的体验问题。
