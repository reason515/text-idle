# v0.1.3 — Death Rest Penalty

**发布日期：** 2026-06-21  
**代号：** 阵亡休憩

在 v0.1.2 基础上调整阵亡惩罚机制，修复卸装入库问题，并完善装备词缀中文展示。

## 战后休息与阵亡惩罚

- 角色阵亡后**不再降低每步恢复速度**；全员 HP/MP 回满后，按**每名阵亡者额外 5 步**休息（计入休息步与探索步）
- 排行榜**效率分母**正确反映阵亡代价，便于比较不同挂机策略

## 装备与 UI

- 修复卸下装备时背包槽位键名错误导致物品丢失或错位的问题
- 装备词缀 **physAtk（物理攻击）** 等属性标签统一为中文展示；戒指 physAtk 词缀正常生效

## 本版本未包含

- 仍无实时聊天、交易市场、PVP 等弱联网功能
- 战术 AI 解析仍依赖玩家自行配置 SiliconFlow API Key

## 反馈

欢迎在团队渠道反馈阵亡惩罚体感、装备操作与词缀展示问题。
