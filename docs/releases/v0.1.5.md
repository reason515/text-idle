# v0.1.5 — Step-Based Stats & Deploy Fix

**发布日期：** 2026-06-22  
**代号：** 步进明晰

统一统计与战报中的「步」口径，并修复生产部署后静态资源 HTTP 404 导致页面无法加载的问题。

## 数据统计

- 主界面**战斗趋势图**横轴由「每场战斗回合数」改为**战斗行动步**，与玩家统计系统的步数口径一致
- 旧存档中仅含回合数的历史数据在读取时**自动迁移**为行动步

## 战斗日志

- 战后休息阶段**阵亡惩罚步**与 HP/MP 常规恢复步**分开展示**，便于在日志中识别额外等待
- 惩罚步使用独立样式，与正常恢复 tick 区分

## 部署修复

- 修复嵌入式 SPA 静态文件在 Gin 路由下返回 **HTTP 404** 的问题；浏览器现可正常加载 **ES module** 脚本

## 本版本未包含

- 仍无 CDN、HTTPS 域名部署
- 战术 AI 解析仍依赖玩家自行配置 SiliconFlow API Key

## 反馈

欢迎在团队渠道反馈趋势图、战报休息展示与部署加载问题。
