# v0.1.5 — Step-Based Stats & Deploy Fix

**发布日期：** 2026-06-22  
**代号：** 步进明晰

统一统计与战报中的「步」口径，并修复部分环境下游戏页面无法加载的问题。

## 数据统计

- 主界面**战斗趋势图**横轴由「每场战斗回合数」改为**战斗行动步**，与玩家统计系统的步数口径一致
- 旧存档中仅含回合数的历史数据在读取时**自动迁移**为行动步

## 战斗日志

- 战后休息阶段**阵亡惩罚步**与 HP/MP 常规恢复步**分开展示**，便于在日志中识别额外等待
- 惩罚步使用独立样式，与正常恢复 tick 区分

## 加载修复

- 修复部分环境下游戏页面无法加载的问题
