# v0.1.1 — Tactics UX Patch

**发布日期：** 2026-06-21  
**代号：** 战术配置优化

在 v0.1.0 基础上优化 AI 战术配置体验：自然语言模板改为场景化叙述、支持将当前战术转为可编辑文案，并合并为单一编辑框，降低上手与微调成本。

## 战术 AI 配置

- 进入战术 Tab 时自动填入**场景化自然语言**模板（战士 OT 拉怪、法师血线分段、牧师治疗 triage 等编号句式，而非结构化字段复述）
- **恢复模板** 一键重置编辑框；**转为自然语言** 将已保存战术写入同一编辑框以便微调
- 模板与编辑**共用一个大文本框**，可直接修改全文后再 AI 解析
- 固定三人组（战法牧）开局默认战术调整，未改战术时也能更稳定作战

## 本版本未包含

- 仍无世界聊天、交易市场、PVP 等弱联网功能
- 战术 AI 解析仍依赖玩家自行配置 SiliconFlow API Key
