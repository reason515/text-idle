# v0.2.0 — Server Idle Combat

**发布日期：** 2026-06-28  
**代号：** 征途不息

战斗推进改由**服务端**计算；关闭浏览器或标签页在后台时，小队仍会继续挂机（最长累计 **24 小时**离线收益）。重新登录后自动同步金币、经验、地图进度与背包。

## 挂机推进

- 战斗回合、结算与休息在服务端执行，不再依赖浏览器前台运行
- 离线或切后台期间最多补算 **24 小时**进度；超出部分不追溯
- 登录后自动拉取最新战斗事件与存档，主界面继续从当前进度推进

## 战斗与界面

- 在线时战斗日志与结算面板**近实时**更新，便于查看战况
- **暂停**按钮仍会暂停服务端战斗；恢复后继续推进
- 首领战解锁**扩编招募**时不再打断挂机；以红点提醒，战斗照常进行

## 存档与装备

- 装备更换、背包变动会更可靠地写入服务端存档
- 招募第 4 名英雄、确认编队后会先保存再进入主界面，避免进度丢失
