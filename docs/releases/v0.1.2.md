# v0.1.2 — Message Board

**发布日期：** 2026-06-21  
**代号：** 全服留言板

在 v0.1.1 基础上上线弱联网**留言板**：原 Feed 区「世界聊天」占位改为可用的全服留言功能，所有玩家可发布留言，内容永久保留，并展示小队名称与发布时间。

## 留言板

- 主界面 Feed Tab **留言板**（`feed-tab-chat` testid 保留）：浏览全服留言、输入并发送
- 后端 `GET /message-board`、`POST /message-board`（需登录）；SQLite 永久存储，无删除接口
- 每条留言展示存档 **teamName**（空则「未命名队伍」）与 **created_at**（UI 本地 `YYYY-MM-DD HH:mm`）
- 默认加载最近 100 条；列表自旧到新排列，新留言追加到底部；支持刷新

## 本版本未包含

- 仍无实时聊天、交易市场、PVP 等弱联网功能
- 战术 AI 解析仍依赖玩家自行配置 SiliconFlow API Key

## 反馈

欢迎在团队渠道反馈留言板体验、内容长度限制与后续社交功能优先级。
