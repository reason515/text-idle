# v0.1.7 — Inline Skill Growth

**发布日期：** 2026-06-27  
**代号：** 成长随行

里程碑技能与属性点改为**主界面内嵌选择**，不再弹出阻塞弹窗；圣骑士前期可更稳地承担副坦；浏览器标签页在后台时战斗日志不再拖慢挂机进度。

## 技能成长

- 达到 **Lv10 / Lv20 / Lv30** 等里程碑时，在英雄详情 **技能** 页内直接选择新技能或强化，无需关闭主界面
- 战斗日志会提示「有待分配的技能/属性点」；主界面与技能页显示**红点**提醒未消耗点数
- 技能卡片展示**逐阶强化路径**，便于预览各 tier 效果

## 圣骑士

- **审判** 产生 **1.25 倍** 仇恨，**正义圣印** 持续期间额外 **+0.15** 仇恨
- Lv10 学会 **奉献** 前，圣骑士也能更稳定地拉住怪物仇恨，适合副坦定位

## 挂机体验

- 浏览器标签页切到**后台**时，跳过战斗日志的 UI 播放延迟，挂机推进不再因前台动画而停滞
- 切回前台后仍正常播放日志，便于查看战况
